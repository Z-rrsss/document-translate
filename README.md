# Document translate（文件翻译）

Document translate（文件翻译）是一个文档翻译 skill。它可以处理单份文件、批量文件及嵌套压缩包，按照文件内容和既定规则，制作中英对照或英文文件，并直接整理为可交付版本。

它会保留原件、已有英文和原文件类型。对于中英混合文档，只补译缺少英文的部分；对于表格、Word 和 PDF，分别按规则保留原有结构并安排译文。处理压缩包时，译件会放回原文件所在的目录及压缩层级。

交付前，skill 要求逐份核对译件的完整性、关键数字和文字以及显示效果。发现错误时，以原件和译件的可视化对照标出问题及位置，供翻译者判断和修正。

使用时调用 `$document-translate`，并提供待处理文件。具体处理和核验规则见 [`SKILL.md`](SKILL.md)。实际可处理的文件格式与交付方式取决于运行环境中可用的文档工具。
